# Планы тренировок — Telegram-бот и Mini App

Бот составляет недельный план тренировок и проводит по нему. Опрос и тренировка проходят
в мини-приложении внутри Telegram: у каждого упражнения есть клип, таймер подхода, отдых
с обратным отсчётом и счётчик сожжённых калорий. Бот присылает напоминания в дни тренировок.

**Демо в браузере:** `https://ИМЯ.github.io/workout_bot/`

## Возможности

- Опрос по одному вопросу: цель, уровень, место тренировок, какие мышцы прокачать,
  дни недели, что беречь (колени, спина, плечи, запястья), вес, напоминания
- План по правилам из библиотеки 52 упражнений: учитывает инвентарь, уровень и ограничения,
  добавляет упражнения на выбранные мышцы
- «День 1» — ближайший тренировочный день начиная с сегодняшнего; дни листаются вкладками и свайпом
- Тренировка: подходы на повторы (секундомер + «Подход выполнен») и на время (отсчёт
  «Приготовься», затем таймер), отдых с крупной картинкой следующего упражнения, «+15 с»,
  пауза, назад, пропуск, звук и вибрация на последних секундах
- Счётчик калорий по формуле MET: во время тренировки, в итогах и за неделю
- День засчитывается, даже если часть упражнений пропущена
- Быстрая тренировка на одну группу мышц — можно сделать сразу после основной
- Новая неделя: когда все дни выполнены, план на следующую составляется сам —
  с прибавкой нагрузки и другими упражнениями
- Напоминания: бот спрашивает время, пользователь пишет его сам (например, 19:30); настройка — `/remind`
- Прогресс хранится в Telegram CloudStorage, интерфейс подстраивается под светлую и тёмную тему

## Как это устроено

```
[📝 Составить план] ──► Mini App: опрос ──sendData──► бот: сохраняет ответы, спрашивает время напоминаний
                                                        │
                        Mini App: план и тренировка ◄───┘ кнопка «Открыть план» (ответы в ссылке ?s=…)
```

Мини-апп — статический сайт в папке `docs/` (GitHub Pages), сервер для него не нужен:
план собирается в браузере из ответов в ссылке, прогресс хранится в CloudStorage пользователя.
Бот нужен для запуска опроса, кнопок и напоминаний.

## Стек

- **Бот:** Python 3.11+, [aiogram 3](https://docs.aiogram.dev/) (FSM для ввода времени), SQLite
- **Mini App:** HTML, CSS, чистый JavaScript без сборки, [Telegram Web Apps API](https://core.telegram.org/bots/webapps)
- **Тесты:** pytest и встроенный `node --test`

## Запуск

1. **Опубликуй мини-апп.** Создай на GitHub публичный репозиторий `workout_bot`, загрузи файлы проекта
   (без `.env`!), затем Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/docs`.
2. **Настрой бота.** Скопируй `.env.example` в `.env`: токен от [@BotFather](https://t.me/BotFather)
   и `WEBAPP_URL` из шага 1.
3. **Запусти:**
   ```bash
   pip install -r requirements.txt
   python bot.py
   ```

Напоминания отправляются по часам компьютера, на котором запущен бот, и только пока бот запущен.

**Обновление мини-аппа.** Telegram кэширует страницу, поэтому при каждом обновлении увеличь
`APP_VERSION` в `handlers/keyboards.py` и номер `?v=` в `docs/index.html`, затем перезапусти бота
и отправь ему `/start`.

## Тесты

```bash
pip install -r requirements-dev.txt
pytest -q
node --test tests/planner.test.js
```

## Картинки упражнений

Кадры взяты из [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (public domain, Unlicense).
Пересобрать библиотеку: `python tools/build_library.py <путь к free-exercise-db/exercises>`.

## Идеи для развития

- История тренировок и прогресс по весам
- Свои видео вместо двух кадров
