# Планы тренировок — Telegram-бот и Mini App

Бот составляет недельный план тренировок и проводит по нему. Опрос и сама тренировка
проходят в мини-приложении внутри Telegram: у каждого упражнения есть зацикленный клип,
таймер подхода, отдых с обратным отсчётом, пауза и пропуск.

**Демо в браузере:** `https://ИМЯ.github.io/workout_bot/` — без Telegram план собирается по правилам.

## Возможности

- Опрос: цель, уровень, место тренировок, число дней, что беречь (колени, спина, плечи, запястья)
- ИИ (Google Gemini) подбирает упражнения **только из библиотеки** — никаких выдуманных упражнений,
  ответ проверяется, числа ограничиваются разумными рамками
- Если ИИ не ответил, план собирается по правилам — бот работает всегда
- План по дням с оценкой длительности, карточка упражнения с клипом и подсказкой по технике
- Режим тренировки: подходы на повторы (секундомер + «Подход выполнен») и на время (обратный отсчёт),
  отдых с кольцом-таймером, «+15 с», пауза, назад, пропуск упражнения, звук и вибрация на последних секундах
- Итог тренировки, отметка выполненных дней; план хранится в Telegram CloudStorage
- Интерфейс берёт цвета из темы Telegram, работает в светлой и тёмной теме

## Как это устроено

```
[📝 Составить план] ──► Mini App: опрос ──sendData──► бот
                                                      │  Gemini выбирает упражнения из библиотеки
                                                      │  (не ответил → план соберёт мини-апп по правилам)
                                                      ▼
                        Mini App: план и тренировка ◄── кнопка «Открыть план» (план в ссылке ?p=…)
```

Мини-апп — статический сайт в папке `docs/` (GitHub Pages), серверная часть не нужна:
план передаётся в самой ссылке, а прогресс хранится в CloudStorage пользователя.

## Стек

- **Бот:** Python 3.11+, [aiogram 3](https://docs.aiogram.dev/), [google-genai](https://ai.google.dev/) (gemini-2.5-flash), SQLite
- **Mini App:** HTML, CSS, чистый JavaScript без сборки, [Telegram Web Apps API](https://core.telegram.org/bots/webapps)
- **Тесты:** pytest и встроенный `node --test`

```
│   ├── index.html, styles.css, app.js
│   ├── planner.js          # план по правилам и проверка плана из ссылки

```

## Запуск

1. **Опубликуй мини-апп.** Создай на GitHub публичный репозиторий `workout_bot`, загрузи файлы проекта
   (без `.env`!), затем Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/docs`.
   Через минуту сайт будет доступен по адресу `https://ИМЯ.github.io/workout_bot/`.
2. **Настрой бота.** Скопируй `.env.example` в `.env` и заполни:
   токен от [@BotFather](https://t.me/BotFather), бесплатный ключ
   [Gemini](https://aistudio.google.com/app/apikey) и `WEBAPP_URL` из шага 1.
3. **Запусти:**
   ```bash
   pip install -r requirements.txt
   python bot.py
   ```

## Тесты

```bash
pip install -r requirements-dev.txt
pytest -q
node --test tests/planner.test.js
```

## Картинки упражнений

Кадры взяты из [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (public domain, Unlicense).
Пересобрать библиотеку: `python tools/build_library.py <путь к free-exercise-db/exercises>`.
В мини-аппе кадры приводятся к единому монохромному стилю одной строкой CSS (`filter` в `styles.css`).
